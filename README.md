# Simple-Python-RAT
A Simple Python RAT I made for EDUCATIONAL PURPOSES ONLY and should NOT be used for any malicious purposes\
\
This is a very simple RAT for python that only works on LAN because I was too lazy.\
also it is not packaged so if you want to use it you have to package it yourself.\
<br>
If you want to use it yourself, put your host machine's LOCAL IP on your LAN into the quotes of\
`
MASTER_IP = ""
`<br>
inside the client script. (also you have to run it in the terminal)\
<br>
The way this RAT works is very simple. Your host just sends the command and the client uses subprocess to execute it and send the output back.\
You can also send or receive files by typing in\
```
download directory-of-file-on-client's-computer 
upload dir-of-file-on-you-computer
 ```
into the `Shell>` after you run. <br>

you can move where you want to send it by just doing cd for mac and idk what for windows.
